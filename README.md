# Змейтрис

Браузерная игра: змейка падает в стакан тетриса. Ты сам рисуешь фигуру — форма застывшей змейки и есть след, который оставила голова.

- **Репозиторий:** https://github.com/USERNAME/REPOSITORY <!-- заменить на свой -->

Стек: **TypeScript + Phaser + Vite + GitHub Pages**. Подробный план MVP: [`MVP-2.md`](./MVP-2.md).

## Игра в пяти предложениях

1. Я управляю змейкой, которая падает в стакан тетриса.
2. Я веду её свайпами и укладываю так, чтобы заполнять линии.
3. За каждую заполненную линию получаю очки, а за несколько линий сразу — намного больше.
4. С каждым уровнем змейка длиннее и быстрее, а ошибку уже не исправить.
5. Игра заканчивается, когда стакан переполнен и новой змейке некуда выползти.

## Управление

| | Телефон | Компьютер |
|---|---|---|
| Влево / вправо / вниз | свайп в любом месте экрана | ← → ↓ или A D S |
| Вести змейку | не отрывая палец: каждые 30 px — новая команда | — |
| Быстрее вниз | свайп вниз, когда змейка и так ползёт вниз | ↓, когда змейка и так ползёт вниз |
| Застыть сразу | свайп вниз, когда змейка стоит на опоре | ↓, когда змейка стоит на опоре |
| Начать | кнопка «Играть» или касание | кнопка «Играть» или любая клавиша |
| Заново | кнопка «Ещё раз» | кнопка «Ещё раз», R, Enter или пробел |
| Пауза | кнопка «II» справа вверху | Esc или кнопка «II» справа вверху |
| Продолжить | кнопка «Продолжить» | Esc или кнопка «Продолжить» |

Вверх и разворот назад нельзя. Быстрые команды копятся в буфер (до 2 штук), поэтому «вправо, вниз» не теряются.

## Правила

- Труба сама ездит над стаканом туда-обратно. Новая змейка выползает там, где труба оказалась, когда застыла предыдущая. Пока змейка вылезает, труба стоит.
- Змейка каждый шаг ползёт в выбранную сторону.
- Упёрлась сбоку в стенку или блок — сама сползает вниз вдоль препятствия.
- Упёрлась вниз — немного стоит (можно успеть повернуть вбок и лечь горизонтально), потом застывает и становится цветными блоками. Если повернуть некуда, застывает сразу. Хочешь застыть раньше — направь её вниз, когда под головой опора.
- Змейка может заползти под нависающий блок и закрыть дыру, которую в тетрисе не закрыть.
- Заполненная строка исчезает. Очки: 100 × линии × множитель за изгибы змейки, которая закрыла линии.
- **Множитель = 1 + число изгибов:** прямая змейка ×1, Г ×2, Z ×3, лесенка из 8 клеток — до ×7. Прямую ставить проще и безопаснее всего, поэтому она и приносит меньше.
- Каждые 5 линий — новый уровень: змейка на клетку длиннее (с 4 до 8) и быстрее.
- Если змейка застыла, не выбравшись из трубы целиком, или под трубой занято — «Стакан полон!».
- Рекорд сохраняется в браузере (`localStorage`).

## Фазы

Правила в обеих фазах одинаковые — с ростом очков меняются только параметры:

| | Фаза 1 | Фаза 2 |
|---|---|---|
| Когда | до 1000 очков | с 1000 очков |
| Труба сдвигается на столбец за | 450 мс | 280 мс |
| Змейка стоит на опоре, прежде чем застыть | 600 мс | 350 мс |

Уровни (по линиям) меняют длину и скорость змейки, фазы (по очкам) — трубу и застывание, поэтому две системы не спорят за один параметр. После «Ещё раз» очки обнуляются, и игра снова в фазе 1.

**Игровое время** — всё, что считается в `Round.tick()` (`round.ts`): шаги змейки (`stepTimer`), движение трубы (`pipeTimer`), пауза перед застыванием (`restMs`). Сцена вызывает `tick()`, только пока идёт игра, поэтому пауза, стартовый экран, конец игры и свёрнутая вкладка не в счёт. **Время браузера** (часы Phaser) используют только украшения: мигание красной трубы, всплывающие надписи, задержка перед карточкой конца игры — на паузе им идти можно.

## Что видно на экране

- **Старт:** экран с правилами; игра начинается кнопкой «Играть», касанием или любой клавишей. После «Ещё раз» он не показывается.
- **Панель сверху:** очки, уровень с полоской до следующего, рекорд (жёлтый, если бьёшь его прямо сейчас), линии и длина змейки квадратиками.
- **Луч под трубой** показывает, куда выползет следующая змейка. Труба и луч мигают красным, если змейка там не вылезет из трубы прямо вниз.
- **Глаза** сразу поворачиваются туда, куда ты нажал, ещё до шага змейки.
- **Змейка на опоре «твердеет»:** перекрашивается в цвет будущих блоков, пока есть время повернуть.
- **«×2», «×3» у головы** — множитель, который даст змейка, если застынет такой формы.
- Застывшие змейки остаются цельными фигурами; заполненные строки вспыхивают; «+600 ×3 за изгибы»; баннер нового уровня; тряска экрана за 3+ линии; вибрация на телефоне.
- **Пауза** (Esc или кнопка «II» справа вверху; включается сама, если свернуть вкладку или приложение): змейка, труба и таймер застывания замирают, команды не принимаются.
- **Под стаканом** — «Фаза 1 · фаза 2 с 1000 очков». В фазе 2 строка жёлтая, при переходе — баннер «Фаза 2».
- **Конец игры:** змейка краснеет, через секунду появляется карточка с причиной, счётом и рекордом.

## Запуск

Нужен **Node.js 22 LTS** (или >= 20.19).

```bash
npm install
npm run dev
```

Открой адрес, который напечатает Vite (обычно `http://localhost:5173/`). Чтобы проверить на телефоне, открой адрес `Network` из терминала — телефон должен быть в той же Wi-Fi.

Проверка перед публикацией:

```bash
npm run typecheck
npm run build
npm run preview   # локальная проверка собранной версии из dist/
```

## Публикация на GitHub Pages

Workflow [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml) собирает и публикует игру после каждого push в `main`.

Первый раз:

1. **Settings → Pages → Build and deployment → Source:** выбери **GitHub Actions**.
2. Во вкладке **Actions** дождись зелёного `Deploy to GitHub Pages`.
3. Ссылка появится в разделе **Pages** — вставь её в начало этого файла.

- движение трубы — `updatePipe()` в `round.ts`;
- застывание и конец игры — `freeze()`, `spawnSnake()`, `gameOver()` в `round.ts`; карточка конца и рекорд — `gameOver()` в `GameScene.ts`;

- свайпы и клавиатура — `input.ts`; что они делают в игре — `handleKey()`, `handleDir()` в `GameScene.ts`, буфер команд — `queueDir()` в `round.ts`;
